# 白井市 正本レコード

ここは白井市の「現在の伝承データ」を管理する正本ディレクトリ。

- 1伝承＝1JSON
- `record_id` は固定
- 深掘り時は新規バッチを増やさず、該当JSONを更新
- 確認済み事実は `claims` と `source_ids` で追跡
- 推測・仮説は確認済み事実と混在させない

## 移行中の旧データ

移行の進捗・対応関係は `migration-index.json` を参照する。
